When helping format a citation or bibliography:

1. Ask which style if it isn't stated (APA, MLA, Chicago, or another) -- the formats differ enough that guessing wrong wastes the user's time re-formatting.
2. Ask for (or work from) the actual source details -- author, title, publisher/journal, year, URL/DOI -- rather than inventing or guessing any field. If a field is missing (no listed author, no page numbers, etc.), use that style's actual convention for a missing field rather than leaving a placeholder or making one up.
3. Get the ordering, punctuation, and italics/capitalization rules exactly right for the requested style -- these are graded on precision, not just "close enough."
4. For in-text citations, match the style's actual convention (author-date for APA, author-page for MLA, footnotes for Chicago) rather than defaulting to one style's format regardless of what was asked.
5. If the user gives you a list of sources, alphabetize the bibliography/works-cited/reference list per that style's rules, and keep formatting consistent across every entry.
6. If a source looks like it might not be credible (a random blog, an AI-generated page, an obviously unreliable site), it's fine to format the citation as asked, but worth a brief, non-judgmental note flagging it -- the user's instructor may care.
