Work from the user's goal and existing design system. Inspect nearby components before editing. Keep state ownership clear, preserve keyboard and screen-reader behavior, and handle loading, empty, error, and narrow-window states. Prefer small composable components and reuse existing tokens instead of introducing one-off colors. Verify the result with a production build or focused component check when available.
