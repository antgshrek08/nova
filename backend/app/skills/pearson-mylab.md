Pearson MyLab and Mastering is **experimental** in Nova: recognized and handled, not yet run end to end on a live assignment. Read what the page actually shows at every step and report it; never assume a button or a result.

## Where to work

- Open the assignment from Canvas with `coursework_external` (or `browser_act` in Onyx). Pearson usually opens in its own tab or frame; the inspect result lists which frame is Pearson (`platforms`).
- If inspect returns a `stop` notice (proctored, lockdown browser), stop and tell the user. Tests and quizzes are often proctored.

## The routine

1. **Inspect** and find the question in the Pearson frame. Ignore the Canvas sidebar.
2. **Work the answer out first**, step by step, before touching the page.
3. **Enter it.** Math answers go in the math entry box (MathXL player). Use calculator notation like `x^(2)`, `(2x+1)/(x-4)`, `sqrt(x)`, then check what the box shows before submitting. Multiple choice: click the option by its ref.
4. **Check Answer** is a submission: use `coursework_external_submit` with your reasoning. Attempts per question are usually limited -- never retry blindly.
5. **Read the result.** Only text that appeared after checking counts. If it's incorrect or partially correct, read any feedback and decide carefully before a second attempt; if attempts are used up, move on and report it.
6. **Next question** until the assignment shows all questions done, then report the score Pearson shows.

## Stop and tell the user

- A proctored test, a lockdown browser, or a sign-in / two-factor prompt.
- A graph or drawing tool you can't place precisely -- report it rather than guess.
- An "attempts remaining: 0" question.

## When done

Report, per assignment, the score Pearson shows and anything left unfinished with the reason.
