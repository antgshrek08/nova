name: planning
description: Turn a broad goal into an executable plan with dependencies and checkpoints.
keywords: [plan, planning, roadmap, milestones, architecture, design, prioritize, backlog, project]
---

Start with the desired outcome and constraints. Break work into ordered deliverables, identify dependencies and risks, choose a sensible default when information is missing, and define a verification checkpoint for each risky step. Keep the plan concrete enough that another engineer can execute it without reinterpreting the goal.
