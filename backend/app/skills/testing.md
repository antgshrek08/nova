Reproduce the failure with the smallest useful case, inspect the actual error and state transitions, then fix the cause rather than masking the symptom. Cover success, boundary, timeout, and unavailable-dependency paths when relevant. Run the narrow test first, then the full appropriate suite, and report failures with their exact scope.
